## Introduction

The PETadex database compiles millions of Logan sequence candidates (predominantly PETase-like enzymes) identified in environmental metagenomic datasets. However, these sequences lack critical ecological context—such as the temperature, pH, and growth media of the source environments. Downstream machine learning tasks, such as protein thermostability prediction, depend heavily on these environmental labels.

To address this characterization gap, we propagate metadata from NCBI SRA libraries and BioSamples. Using BioSample accessions, we map sequencing runs to detected TaxIDs using NCBI SRAstat/Athena tables. We then query the BacDive API to fetch physiological and culture traits for these organisms. Finally, by joining the taxa relative abundances with BacDive traits, we perform statistical inference to calculate abundance-weighted and unweighted environmental conditions (pH, temperature) for each sample, which are subsequently mapped back to the candidate sequences.

## Objectives

1. **SRA-to-Taxonomy Mapping**: Link the 6.81 million BioSamples from `petadex_biosamples.csv` to their corresponding SRA runs and the taxonomic IDs of detected organisms via AWS Athena queries on SRA Metadata and SRA STAT tables.
2. **BacDive Trait Harvesting & Cleaning**: Extract physiological and growth conditions (temperature, pH) from the BacDive database for all unique TaxIDs, cleaning raw text ranges into structured numeric values.
3. **Out-of-Core Processing**: Process 156 GB of raw SRA stat mapping tables locally using chunked streaming in pandas to compute unweighted and weighted mean environmental optimums per BioSample.
4. **Data Integrity Verification**: Run anti-join anomaly detection queries on AWS Athena to guarantee 100% data retention.
5. **PostgreSQL Schema & Web Integration**: Build normalized database tables in PETadex PostgreSQL and integrate environmental metadata dropdowns on the candidate sequence pages.

## Data Integrity & Anomaly Detection

To verify that our out-of-core pandas chunk scripts (`process_samn2.py`, `process_samn3.py`, `process_remaining_samn.py`) did not drop any valid BioSamples during local processing, we uploaded the compiled output `biosample_bacdive_means.csv` to S3 and ran an anti-join query in AWS Athena:

```sql
SELECT DISTINCT c.biosample
FROM combined_query_results c
JOIN bacdive_clean b 
    ON CAST(c.taxon_id AS INT) = b.taxon_id
LEFT JOIN biosample_bacdive_means m 
    ON c.biosample = m.biosample
WHERE 
    regexp_like(c.biosample, '^(SAMN|SAMEA|SAMD|ERS)[0-9]+$')
    AND regexp_like(c.taxon_id, '^[0-9]+$')
    AND (b.temp_optimum IS NOT NULL OR b.ph_optimum IS NOT NULL)
    AND m.biosample IS NULL;
```

**Result**: `0 rows returned` (Scanned 299.56 GB in 32.94s). This proves **100% data retention**—not a single valid BioSample was omitted during chunk processing.

## Results & Discussion

### Final Coverage Summary
- **Total Target BioSamples (`petadex_biosamples.csv`)**: `6,810,053`
- **Successfully Annotated BioSamples (`biosample_bacdive_means.csv`)**: `5,435,158` (**79.81% coverage**)
- **Natural Drop-offs (~20.19%)**: 1,374,895 samples lacking bacterial isolates in BacDive (viral/fungal metagenomes, human host reads, uncultivated candidate phyla).

### Environmental Context Validation (Sanity Checks)
- **Lowest Temperature BioSample (`SAMEA6620430`)**: Mean Temp Optimum = **14.0°C** (from 4 BacDive organisms) | Context: *Coastal sea water (United Kingdom)*.
- **Highest Temperature BioSample (`SAMEA20004763`)**: Mean Temp Optimum = **57.5°C** (from 4 BacDive organisms, incl. *Thermus thermophilus* HB27) | Context: *Hyperthermal environmental assembly*.
- **High-Richness Hydrothermal Sample (`SAMD00204259`)**: Mean Temp Optimum = **46.5°C** (from 28 BacDive organisms) | Context: *Hot spring*.
