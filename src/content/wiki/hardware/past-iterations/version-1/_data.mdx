When developing the system architecture, we explored various possible methods to connect the bioreactors to the laptop. We considered using Wi-Fi, Bluetooth, USB FlashDrive, and USB serial ports. Upon analyzing the advantages and disadvantages of each of these methods, we settled on using USB serial ports for data and controls transmission. When searching for the corresponding hardware, we came across USB hubs which connect multiple USB connections to a single port on a laptop. Then, we mapped out the following hardware flow diagram to better visualize those connections assuming we have 7 available USB ports.

### Design of Experiments (DoE)

#### Testing the different USB hubs

To determine which type of USB hub could reliably connect an Arduino Nano to a laptop, both powered and non-powered USB hubs were tested. We observed whether the Arduino was recognized by the laptop by observing the COM ports through device manager to ensure a serial connection was established.

### Metrics and Experimental Data

#### Testing the different USB hubs

When the Arduino Nano was connected to the powered USB hub, the Arduino did not establish a connection with the laptop. However, when connected to the non-powered USB hub, the Arduino was successfully recognized by the laptop and appeared in Device Manager as connected through a COM port. Based on these results, we chose to use non-powered USB hubs.

### Next Steps

Moving forward, the user interface must be significantly improved so that the software can be accessible to researchers. This includes ensuring data can be transferred from the Arduino to the user interface, verifying that controls can be received by the Arduino, adding more buttons and sliders, building graphing features, testing whether the program can be launched with minimal steps, and ensuring that text and visuals are easy to interpret and navigate.
