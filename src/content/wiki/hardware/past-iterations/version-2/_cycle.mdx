<EngineeringStage id="design">

Building onto our learnings from the previous iteration, we wanted to make improvements based on what each of the subsystems lacked during the experiments we performed. We planned to create a soldered protoboard to remove some unnecessary mass and repetitive wiring, design some housings for our electronics to improve the safety of our device, fix the fan RPM, and improve temperature control.

Additionally, we wanted to begin integrating each of the subsystem components to fix any bugs or unexpected errors in communication between the Arduino nano and laptop UI USB port. As our first pass, we standardised communication between these two devices by passing JSON messages between them.

Arduino to laptop UI: passing 2 OD sensor, temperature sensor, and fan RPM readings for the UI to display.

Laptop UI to Arduino: passing target temperature to heater, target power to pumps, target PWM signal to fan to actuate commands based on how the user interacts with the UI.

We purchased a new fan with better lower RPM control, established a stronger connection between the UI and the Arduino, improved temperature control loops, and added more OD600 features.

<EngineeringStage id="learn">

From testing, we learned that there were some issues with the calibration integration, and that there were some issues with setting the fan RPM from the computer UI. We plan to resolve this through some rigorous debugging and future experimentation to ensure that our OD600 readings are accurate and work properly for every experiment. We also realised that the housing was not entirely ergonomic to assemble, and fittings could be improved. In future iterations, we plan to take into consideration the space to thread each wiring to the perfboard for each component, so that we can design a housing that improves the wiring experience.
