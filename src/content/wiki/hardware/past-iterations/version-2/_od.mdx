### Main Function(s) + Requirements

The main improvements of V2 are the stability of the I2C wiring and the automatization of converting nOD to OD600. V1’s code and features already accurately report nOD values (with errors stemming from CAD housing rather than OD), so V2 improvements stem from adding features, not necessarily refining previous ones. ### Code

Added to the pseudocode is

6. Determine if OD600 is requested by user and if so:
   - Record low, middle, high nOD values and plot it against spectrophotometer readings
   - Utilize the three points to generate a quadratic line of best fit
7. **Unchanged:** Convert raw photodiode readings to nOD
8. Convert nOD to OD600 if requested to do so
9. Plot nOD to determine the log growth phase of a bacterial culture

Below are the key variables and formulas accomplishing the new pseudocode.

| Variables explained                                                                                                                                                                                                                                                                                                                                                                          | Formulas explained                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spectro** → User input of 1 for spectrophotometer readings and 0 if not required.<br /><br />**(x[3], y[3])** → Three points representing a low, middle, and high culture density, where the x coordinate is the nOD value and the y coordinate is the OD600 value (from a spectrophotometer).<br /><br />**a, b, c** → The coefficients for the quadratic line of best fit, ax² + bx + c. | **Calculating coefficients:**<br />`a = Da / D; b = Db / D; c = Dc / D;`<br /><br />Cramer’s rule: each coefficient is its modified determinant (Da, Db, or Dc) divided by the main determinant (D). These determinants are calculated using the three (x, y) calibration points.<br /><br />**Converting nOD to OD600:**<br />`a * nOD * nOD + b * nOD + c`<br /><br />Converts nOD to OD600 using the quadratic calibration curve.<br /><br />If the absolute value of the determinant is less than 0.000001, the calculation is treated as unstable and the quadratic coefficients cannot be reliably calculated. |

### Next Steps

To better visualize growth of a bacterial culture, a graph capable of showcasing the log growth phase of a bacterial culture should be implemented. This would allow the bioreactor to identify when a culture is growing at the maximum rate, and thus take media in/out to keep the max growth rate. Additionally, expanding the wavelengths collected from one color (600nm/orange) to multiple colors allows the bioreactor to detect changes from dye release, which applies to iGEM toronto’s experiments.
