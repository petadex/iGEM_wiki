### Design Modifications

The 5V pin on the Arduino Nano is unregulated and is thus sensitive to voltage fluctuations. While the QC/PD trigger boards provide 5V, the actual voltage measured by the multimeter can fluctuate, especially when high-power components are turned on and off (heater, pumps).

<br />

Thus, we decided to use the VIN pin, which accepts less stable sources from 7-12V. This makes the Nano incompatible with the rest of the 5V electronics, which requires a separate QC/PD trigger board set to 9V. This forms the Arduino power module, which is shared between 7 bioreactors to minimize cost per bioreactor.

### New Design of Experiments

#### Arduino power supply testing

This tests the stability of the Arduino Nano power module, especially in longer experiments. The number of crashes (if any) will be recorded using a script while the Nano runs for 24 hours and operates the bioreactor as normal.

1. Set up the Arduino power supply module and connect it to a bioreactor.
2. After 24 hours, record the number of crashes (if any).

### Metrics and Experimental Data

Isolated tests of the power subsystem were not performed. However, during the full integration of the bioreactor for E.coli growth, the power systems were activated for 1.5 hours and then 6 hours on back-to-back days. During these experiments, no power outages or unexpected changes in current draw or power consumption based on components was observed. Thus, the full subsystem integration provides evidence that the power system functions correctly for an extended period of time.
