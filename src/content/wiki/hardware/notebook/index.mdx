<PageTab id="experiments" label="Experiments">

Reusable subsystem validation protocols (temperature, pump, OD). Use these as living RRF / DoE references — dated bench work lives in the Journal tab.

**Temperature — Experiment 1: Sensor accuracy (25–90 °C)**

**Purpose.** Validate and calibrate candidate temperature sensors across the bioreactor operating range.

**Sensors under test.** DFRobot waterproof digital; Adafruit analog contact; Adafruit digital contact; thermocouple + amplifier; surface-mount thermistor; analog IR.

**Process.**

1. Boil ~200 mL water and pour into a 300–500 mL beaker.
2. After 3 minutes, place the test sensor and a known-accurate probe in the water.
3. Record both readings every 30 s until the reference reaches 25 °C.
4. Repeat for three trials per sensor; plot and calibrate if needed.

![Temperature sensor validation setup](https://static.igem.wiki/teams/6187/wiki/hardware-notebook/experiments/doe-temp-sensor-setup.avif)

**Temperature — Experiment 2: Heater performance**

**Purpose.** Measure whether a heater can bring ~35 mL in a 40 mL vial to a set point (40–80 °C) in a representative housing.

**Heaters under test.** DFRobot PTC; custom SMT resistor array; custom nichrome coil.

**Process.**

1. 3D-print a ~4 mm vial housing (PETG preferred) with voids for heat retention.
2. Power the heater (5 V / 2 A); use TIM between heater and housing.
3. Log vial temperature every 30 s until 80 °C or plateau &gt;30 min; note current deviations &gt;20%.
4. Three trials per heater; plot temperature vs time.

![Heater performance test setup](https://static.igem.wiki/teams/6187/wiki/hardware-notebook/experiments/doe-heater-setup.avif)

**Pump — Experiment 1: Mass-flow consistency**

**Purpose.** Confirm peristaltic mass flow stays consistent across repeated trials at fixed PWM.

**Pump — Experiment 2: Flow vs PWM**

**Purpose.** Map flow rate against PWM duty cycle to set UI / firmware limits.

**Pump — Experiment 3: Small-volume input**

**Purpose.** Check accuracy when dispensing small liquid volumes (relevant to assay top-ups).

**OD — Experiment 1: Dye concentration series**

**Purpose.** Assess OD sensor range, min/max readable density, and collection time needed for stable readings using dye standards.

**OD — Experiment 2: OD vs temperature**

**Purpose.** Check OD accuracy across the temperature sweep the bioreactor will run.

**OD — Experiment 3: OD vs stir-bar speed**

**Purpose.** Find stir speeds / sensor heights that minimize stir-bar interference and measure any collection-time delay.

<PageTab id="v1" label="V1">

**What V1 set out to prove**

V1 focused on a cheap, offline-friendly, multi-unit-friendly bioreactor using common components: temperature control, pumping, OD sensing, and basic user control — without requiring Bluetooth or expensive commercial platforms.

**Cost and power snapshot (HP inputs)**

| Item | Peak power (approx.) | Notes |
| --- | --- | --- |
| Heater | ~5 W | Often duty-cycled |
| Arduino Nano | ~1 W | 5 V × ~0.2 A |
| Peristaltic pumps (×3) | ~9 W peak | ~2.5–3 W each |
| **Peak total** | **~15 W** | All continuously on |
| **Duty-cycled estimate** | **~4.5 W** | Heater + pumps ~25% on |

Assembly / cost goals under discussion: **&lt;100 minutes** to assemble and **&lt;$100** BOM targets (component list still iterating — heater, thermocouple, pumps, fan, Nano, breadboard, wiring).

![V1 post-mortem overview](https://static.igem.wiki/teams/6187/wiki/hardware-notebook/v1/v1-postmortem-overview.avif)

**Post-mortem by subsystem**

![V1 subsystem reflection board](https://static.igem.wiki/teams/6187/wiki/hardware-notebook/v1/v1-postmortem-subsystems.avif)

| Subsystem | Observations | Open questions | V2 direction |
| --- | --- | --- | --- |
| Heating / temperature | Slow heat-up; ~45 °C in ~30 min; aiming toward 80 °C with better TIM / insulation / contact area; control about ±0.6 °C | Probe accuracy vs kitchen reference; fan interaction with heater | Improve thermal interface and insulation; validate probe |
| OD | Sensor returns readings | Needs calibration; cleaner wiring | Calibrate against spectrophotometer; SoftWire / dual-sensor addressing |
| Pumping | Tube spacing on vial top is tight | In/out water tests; larger vial | Horizontal pump drawers; PWM map from DoE |
| Integration / UI | Multi-device serial fragile when one port fails | Powered USB hubs (charge-only vs data); JSON command protocol | Tkinter / serial dashboard with blank/dark OD setup; error isolation per reactor |

**V2 control intent (from late-summer notes)**

- Setup flow: dark (no vial) → blank vial → run, with reference stored for nOD.
- Pumps: stop + PWM / power percent slider (experimentally bounded).
- Temperature: target + continuous feedback.
- Prefer JSON over serial for commands/telemetry; plan for &gt;2 Arduinos needing powered data-capable hubs.
